# Keyboard

Polybench is built to be driven from the keyboard, with one hand free for a probe. Press `?` outside an input box for the in-app list. On macOS, Ctrl and Cmd both work where Ctrl is shown.

## Everywhere

| Key | Does |
|---|---|
| `?` | Keyboard help |
| `c` | Add a note linked to what you are looking at (when no input box has focus) |
| Alt+C | Add a note, from anywhere |
| Ctrl+K | Jump to the Assembly aid scan box |
| Ctrl+B | Collapse or open the left panel |
| Ctrl+J | Collapse or open the bottom panel |
| Alt+Left / Alt+Right | Previous or next board |
| PageUp / PageDown | Previous or next board |

## Test entry

| Key | Does |
|---|---|
| Enter | Accept the typed value, or the proposed value when the box is empty, then move on |
| Alt+A | Move the focus into the Anomalies strip (Tab reaches Redo and Add note) |
| Enter, Enter | Replace an accepted value (the first press asks) |
| Shift+Enter | Record a FAIL or a review value |
| Esc | Clear the box |
| Up / Down | Previous or next test |
| `y`, `n` | Quick answer for a yes/no test, then Enter |
| `1`, `2`, `3`, ... | Quick answer for a choice test, then Enter |
| Any character | Starts typing in the input box |

## Assembly aid

| Key | Does |
|---|---|
| Enter in the scan box | Resolve the scan or typed text |
| Enter (empty page or box) | Place the current line on the ticked boards, or take the next line |
| Up / Down | Previous or next BOM line |
| Esc | Cancel an auto-place grace |

## Dialogs

| Key | Does |
|---|---|
| Ctrl+Enter | Save a note |
| Esc | Close or cancel |
| `1` to `9` | Pick a numbered answer when an action asks a question |

## AOI issue review

| Key | Does |
|---|---|
| `y` / `n` / `u` | Confirmed defect / not a defect / unsure |
| Backspace or `0` | Clear the decision |
| Right / Left, `j` / `k` | Next or previous candidate |
| `t` or `/` | Write a note on the candidate |
| `f` | Fit the crop |
| `e` | Export the reviewed result |
| Space or `b` | Open or close the board view |
| `s` | Board view: silkscreen overlay on or off |
| `r` | Board view: refit |
| `i` | Board view: add mode for a missed issue |
| Esc | Leave add mode, or close the board view |

## Photos viewer

| Key | Does |
|---|---|
| Left / Right | Previous or next photo |
| Esc | Close |
